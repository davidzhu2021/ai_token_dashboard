# 收款码图片存放目录

把收款码图片放在这里，然后在 `.env` 里指向它：

```
MANUAL_PAY_ENABLED=true
MANUAL_PAY_ALIPAY_QR=/assets/pay/alipay.png
MANUAL_PAY_WXPAY_QR=/assets/pay/wxpay.png
```

`/assets` 已挂载为静态目录，放进来即可通过上面的路径访问。也可以改用外链
`https://...`，配置项只放行 `http(s)://` 与站内根路径 `/`。

注意：

- 收款码图片属于收款凭证，不要提交到仓库。部署时手工上传到服务器的同名目录，
  或改用外链。
- 个人收款码没有支付回调，额度不会自动到账；用户提交付款说明后，必须由管理员在
  「充值管理 → 待确认到账」里核对收款流水后确认。
- 正式对外收款请改用商户号（`EPAY_*`），个人收款码只适合小规模内部试运行。
